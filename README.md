# MF AI — Mini Fire AI

ایجنـت هوشمند ساخت بازی اندروید که داخل **Termux** اجرا می‌شود.

## ویژگی‌ها

- چت مستقیم با AI داخل Termux
- ساخت و مدیریت فایل پروژه
- دانلود با اینترنت کاربر
- نصب Android Command-line Tools + SDK (با اجازه)
- تلاش برای بیلد و تولید APK
- کاملاً رایگان (منابع و اینترنت کاربر)

## پیش‌نیاز

1. نصب **Termux** (ترجیحاً از F-Droid)
2. دسترسی به اینترنت
3. فضای خالی مناسب (حداقل ۲-۳ گیگ برای SDK)

## نصب سریع

داخل Termux این دستورات را بزن:

```bash
pkg update -y && pkg install -y git
# فایل‌های پروژه را داخل Termux کپی یا کلون کن
cd mf-ai
bash install.sh
```

بعد از نصب:

```bash
ollama pull qwen2.5-coder:7b
mfai
```

## دستورات داخل برنامه

- `/new نام-پروژه`     ساخت پروژه جدید
- `/open نام-پروژه`    باز کردن پروژه
- `/list`              لیست پروژه‌ها
- `/build`             بیلد Debug
- `/build-release`     بیلد Release
- `/sdk`               نصب/بررسی SDK
- `/status`            وضعیت
- `/help`              راهنما
- `/exit`              خروج

هر پیام دیگری را مستقیم به AI بفرست.

## نکته مهم درباره بیلد APK

بیلد واقعی APK روی گوشی سنگین است و به فضای زیاد + زمان نیاز دارد.
اگر بیلد داخل Termux شکست خورد، AI کدها و ساختار پروژه را کامل تحویل می‌دهد تا بتوانی از روش‌های دیگر استفاده کنی.
